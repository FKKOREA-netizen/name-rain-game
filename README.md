# 이름비 설치형 웹앱 (PWA)

## 이번 변경
- 낙하 속도 증가를 약 2.2배 빠르게 조정했습니다. 기존에는 68.75초에 최고 기준 배율 2.25배에 도달했지만 이제는 31.25초에 도달합니다.
- 시작 낙하 속도와 개별 물체의 최고 속도 제한(화면 높이의 1.12배/초)은 유지합니다. 물체마다 75~135%의 무작위 속도 보정이 있어 일부는 더 일찍 상한에 도달합니다.
- Android 휴대폰/태블릿과 iPhone/iPad에서 홈 화면에 추가해 실행하는 PWA입니다. 아이콘, 앱 이름, 독립 실행 화면, 오프라인 게임 파일 캐시가 포함됩니다.
- APK/IPA 파일이나 앱스토어 등록 앱이 아닙니다. 브라우저에 따라 설치 메뉴·표현·지원 범위가 다릅니다.
- 캐릭터 이름 입력, 강조된 점수 카드, 온라인 랭킹 코드는 유지했습니다.

## 현재 상태 — 반드시 확인
아직 온라인 배포 주소 및 랭킹 저장소가 생성·연결된 상태가 아닙니다. ZIP을 푼 뒤 HTML 파일을 직접 여는 것만으로 휴대폰에 설치되지는 않습니다. 설치하려면 본인 계정으로 HTTPS 정적 웹 호스팅에 업로드해야 합니다.
랭킹 저장소 없이도 웹에 배포하면 게임 설치/플레이는 가능하지만 공유 랭킹은 작동하지 않습니다.

## 배포하기
1. 이 ZIP을 풉니다.
2. 공유 랭킹을 사용하려면 RANKING_SETUP.md에 따라 Supabase 프로젝트를 만들고 setup.sql을 실행합니다. 이전 버전에서 이미 만든 저장소가 있다면 SQL을 다시 실행하지 말고 같은 Project URL과 공개 키만 재사용하세요.
3. index.html의 `const ONLINE`에 Project URL과 공개용 publishable key(또는 legacy anon key)를 채웁니다. **service_role/secret 키와 DB 비밀번호는 절대 넣지 않습니다.**
4. index.html, sw.js, manifest.webmanifest, 모든 icon-*.png를 같은 폴더 구조 그대로 HTTPS 정적 웹 호스팅에 올립니다. Netlify, Cloudflare Pages, GitHub Pages 등의 본인 계정에서 배포할 수 있습니다. 각 서비스의 현재 조건/요금/절차는 관리 화면을 확인하세요. 사이트 빌드가 필요 없는 정적 파일입니다.
5. 받은 HTTPS 웹 주소를 다른 사용자에게 공유합니다. 카카오톡 등의 앱 내부 브라우저에서 설치가 안 보이면 Chrome이나 Safari에서 주소를 여세요.

## 휴대폰·태블릿에 설치하기
### Android
- Chrome으로 배포된 HTTPS 주소에 접속합니다.
- 게임 상단 ‘앱 설치’ 버튼을 누릅니다. 브라우저가 설치 요청을 지원하면 설치 창이 표시됩니다.
- 버튼으로 안 되면 Chrome 메뉴의 ‘앱 설치’ 또는 ‘홈 화면에 추가’를 확인합니다.
- 설치 후 홈 화면의 이름비 아이콘으로 실행합니다.

### iPhone / iPad
- Safari에서 배포된 HTTPS 주소를 엽니다.
- 공유 메뉴에서 ‘홈 화면에 추가’를 선택합니다. OS에 ‘웹 앱으로 열기’ 선택 항목이 표시된다면 켭니다.
- 홈 화면에 생긴 이름비 아이콘으로 실행합니다. 자동 설치 팝업은 제공되지 않을 수 있습니다.

## 오프라인 및 업데이트
- 최초에는 인터넷에 연결한 상태로 접속해 파일 캐시가 완료돼야 합니다. 브라우저가 캐시를 지우거나 저장을 제한하면 오프라인 실행이 안 될 수 있습니다.
- 게임 자체는 캐시 후 오프라인에서도 실행할 수 있지만 랭킹 등록·조회에는 항상 인터넷이 필요합니다.
- 오프라인 기록의 자동 업로드는 없습니다. 게임 종료 화면에서 연결 복구 후 등록을 다시 시도할 수 있으나 페이지를 닫으면 미등록 기록은 사라집니다.
- 업데이트 시 새 파일을 같은 위치에 업로드합니다. sw.js의 CACHE 값을 v2, v3처럼 올리면 새 정적 파일 캐시가 준비됩니다. 기존 앱 창을 모두 닫고 다시 열어 새 버전을 사용하세요. 진행 중인 게임을 강제로 새로고침하지 않도록 자동 재시작은 하지 않습니다.

## 확인 항목
- 휴대폰/태블릿에서 설치 후 앱 아이콘·독립 화면 실행 확인
- 캐릭터 이름 입력 → 게임 플레이 → 종료 → 이름 입력 후 기록 등록
- 다른 기기에서 랭킹을 새로고침해 같은 기록 조회
- 랭킹 미연결/네트워크 끊김 안내 확인
- 현재 파일은 코드·로직·필수 리소스 검사를 마쳤습니다. 실제 기기 설치, HTTPS 배포, 온라인 DB 연결 테스트는 아직 하지 않았습니다.

랭킹의 공개 기록/부정행위 방지 한계 등 자세한 사항은 RANKING_SETUP.md를 참고하세요.
